# Word Mine

Браузерная игра для компании от 3 человек. Размер комнаты настраивается, ограничения в 10 игроков нет. Вход по коду комнаты и нику — пароль не нужен.

## Запуск

Рекомендуется Node.js 24. Для Vercel используется официальный драйвер Neon; локальный сервер хранит комнаты в SQLite.

```sh
cd wordmine-game
npm install
npm start
```

Откройте http://localhost:3000. Для друзей в той же сети используйте IP компьютера, например `http://192.168.1.20:3000`. Приглашения автоматически используют адрес, по которому вы открыли игру. Для игры через интернет разместите сервер на хостинге с Node.js и постоянным диском, HTTPS и доступным портом. Например, команда запуска `npm start`, рабочая папка `wordmine-game`, постоянный диск для `wordmine-game/data`.

Можно задать `PORT` (по умолчанию 3000) и `DATA_DIR` (по умолчанию `wordmine-game/data`). Комнаты хранятся в SQLite и переживают перезапуск. Неактивные комнаты удаляются через 7 дней. У каждого игрока отдельный браузер/вкладка; обновление страницы восстанавливает участие через sessionStorage. Если вкладка или сессия потеряна, войдите по прежнему коду комнаты с тем же ником: игрок, очки и сыгранные роли восстановятся без дубликата. Регистр ника не важен. Новая сессия заменяет прежнюю; для этой игры код комнаты и ник служат способом восстановления. После выхода или удаления запись игрока сохраняется в комнате, чтобы при возвращении не обнулялись очки и баланс ролей. Удаление завершает прежнюю сессию, но не запрещает новый вход по коду комнаты и нику. Бывший ведущий при возвращении не забирает роль у нового; в пустой комнате ведущим станет первый вернувшийся. При старте новой партии очки и сыгранные роли сбрасываются и у временно отсутствующих игроков. Пустая комната с сохранёнными игроками доступна для возвращения до истечения срока хранения (7 дней неактивности).

## Возможности

- Комнаты по ссылке или четырёхзначному цифровому коду (например, `1234` или `0275`), вход без пароля.
- Любой размер от 3 до 1 000 000 мест либо пустое поле без лимита приложения. Реальная нагрузка зависит от хостинга; проверена одновременная игра 13 клиентов, нагрузочное тестирование больших групп не выполнялось.
- Ведущий может начать при трёх игроках без подтверждения готовности. Вход и удаление участников доступны во время игры. При выходе ведущего его роль переходит оставшемуся игроку.
- Секретные роли, 60 секунд на установку мин, ответы текстом или вслух без таймера. Минёры видят установленные слова друг друга во время минирования и объяснения; объясняющему и угадывающему мины скрыты до результатов хода.
- Заявка на подрыв с подтверждением ведущего, очки, смена ролей и итоговая таблица.
- Настройка количества кругов, 200+ встроенных слов и свой словарь.
- Русский интерфейс, адаптация к телефонам, управление с клавиатуры.

Общение — за столом или в стороннем голосовом/видеозвонке. Распознавания речи нет. Совпадение текстового ответа проверяется без учёта регистра и ё/е; синонимы и устные ответы подтверждает объясняющий или ведущий. Мина — слово или фраза от 1 до 20 символов, включая пробелы; пробелы внутри фразы разрешены. На минирование даётся 60 секунд, объяснение начинается раньше, если все установили мины. Объяснение и угадывание не ограничены по времени. Новые коды комнат состоят ровно из четырёх цифр; старые приглашения продолжают работать. При неизменном составе один круг — каждый игрок один раз объясняет и один раз угадывает. При правильном ответе оба получают по очку; при подтверждённом подрыве очко получают авторы сработавшего слова. При входе и выходе игроков очки и счётчики сыгранных ролей сохраняются. Новые участники играют минёрами в текущем ходу, а будущая очередь пересчитывается: приоритет у тех, кто реже играл соответствующую роль. Каждый оставшийся участник получает как минимум по одной роли объясняющего и угадывающего за настроенный круг, включая вошедших поздно. При уходе активного объясняющего или угадывающего незавершённый ход начинается заново со свежим словом (если словарь содержит другое слово), без очков и без зачёта незавершённых ролей. Уход минёра убирает его мину и не сбрасывает ход. Если осталось менее трёх человек, игра ставится на паузу и автоматически продолжается при возвращении состава к трём. При изменении состава могут добавляться партнёрские ходы, чтобы никто не остался без нужной роли.

## Проверка и сборка

```sh
cd wordmine-game
npm test
npm run build
```

Тесты проверяют приватность, вход по коду, права, размеры комнат, таймеры, очки, смену ролей и конкурентные запросы. `npm run build` создаёт самостоятельный Cloudflare Worker в `dist/server/index.js` и D1-миграцию в `dist/.openai/drizzle`. Hosted-версия использует D1 binding `DB`; локальная — встроенный `node:sqlite`. Миграции применяются при публикации Sites.

Механика вдохновлена [«Словами-минами» Salofun](https://salofun.ru/game/word-bomb). Код, интерфейс и словарь написаны для этого проекта.

## Cloudflare Workers + D1

Текущая цель размещения — Cloudflare Workers. `wrangler.jsonc` связывает Worker `wordmine-game` со встроенной базой D1 через `env.DB`; каталог миграций — `drizzle`. Для этого варианта `DATABASE_URL` и Neon не требуются. Все страницы, стили и клиентский код включаются в один Worker-файл при сборке.

Первоначальная настройка в своём аккаунте Cloudflare:

```sh
cd wordmine-game
npm ci
npm run cloudflare:login
npm run cloudflare:db:create
npm run cloudflare:db:remote
npm run cloudflare:check
npm run cloudflare:deploy
```

`cloudflare:db:create` создаёт выделенную базу `word-mine-rooms` и записывает её настоящий `database_id` в `wrangler.jsonc`. Перед следующими публикациями повторно создавать базу не нужно: применяйте новые миграции командой `cloudflare:db:remote`, затем запускайте `cloudflare:deploy`. Сохраняйте `migrations_dir: "drizzle"` у binding `DB`. Wrangler сообщит адрес `workers.dev` после успешной публикации. Для автоматических сборок Cloudflare используйте рабочую папку `wordmine-game`, команду сборки `npm run build` и команду публикации `npm run cloudflare:deploy`.

Локальный запуск Worker и базы:

```sh
npm run cloudflare:db:local
npm run cloudflare:dev
```

`cloudflare:check` проверяет собранный Worker, SQL-запросы D1, вход без пароля, роли, ответы и восстановление по нику, затем выполняет `wrangler deploy --dry-run` без публикации. `.wrangler/` и файлы локальных секретов исключены из Git. Комнаты прежнего хостинга не переносятся автоматически в новую D1-базу.

## Предыдущий хостинг (Vercel)

Проект Word Mine в Vercel подключён к выделенной базе комнат через существующую интеграцию Neon (Free). Node.js 24, функции и база в регионе Frankfurt (`fra1`). У Vercel локальный диск непостоянный, поэтому API использует Postgres, общий для всех экземпляров функций. Локальный SQLite и сборка Cloudflare остаются доступными.

Конфигурация: `vercel.json`, API: `api/index.js`, хранилище с атомарной проверкой версии: `src/postgres-store.js`. Переменная `DATABASE_URL` поступает из интеграции Vercel и не попадает в клиентский код. `.env*`, `.vercel`, локальные данные и сборки исключены из Git/загрузки.

```sh
cd wordmine-game
npm ci
vercel env run --environment production -- npm run db:migrate
vercel env run --environment production -- npm test
```

Схема Postgres: `migrations/postgres/001_rooms.sql`; миграция идемпотентна. Интеграционный тест создаёт отдельную тестовую комнату, проверяет 13 одновременных игроков, конфликты записи и сохранение данных между обработчиками, затем удаляет только эту тестовую комнату. Без `DATABASE_URL` он пропускается. Существующие комнаты старой Sites-версии автоматически не переносятся.
