# Word Mine

Браузерная игра со словами и секретными ролями для компании от 3 человек.

**[Играть в Word Mine →](https://wordmine-game.ghbit.workers.dev)**

Готовая игра доступна по ссылке: ничего устанавливать не нужно. Откройте её на телефоне или компьютере, создайте комнату и пригласите друзей.

## Как начать

1. Откройте [wordmine-game.ghbit.workers.dev](https://wordmine-game.ghbit.workers.dev).
2. Создайте комнату и укажите ник.
3. Отправьте друзьям ссылку-приглашение или четырёхзначный код комнаты.
4. Когда соберётся минимум 3 игрока, ведущий может начать игру.

Каждый участник играет в своём браузере или вкладке. Для общения соберитесь за одним столом или подключитесь к голосовому/видеозвонку. Регистрация и пароль не нужны.

## Как играть

- В каждом ходу один игрок объясняет слово, другой угадывает, остальные становятся минёрами.
- У минёров есть 60 секунд, чтобы установить секретные слова-мины. До конца таймера свою мину можно заменить.
- Объясняющий и угадывающий не видят мины до результатов хода. Минёры видят слова друг друга.
- Угадывать можно текстом или вслух. Объяснение и угадывание не ограничены по времени.
- При правильном ответе объясняющий и угадывающий получают по очку. При подтверждённом ведущим подрыве очко получают авторы сработавшей мины.
- Роли меняются. При неизменном составе за один круг каждый игрок по разу объясняет и угадывает.

Количество кругов и размер комнаты настраиваются. В игре есть 500 встроенных слов и возможность добавить свой словарь. Новые участники могут присоединяться во время партии; если игроков становится меньше трёх, игра ставится на паузу.

## Возвращение в комнату

Обновление страницы восстанавливает участие. Если вкладка или сессия потеряна, войдите по прежнему коду комнаты с тем же ником — очки и сыгранные роли сохранятся. Регистр ника не важен; новый вход заменяет прежнюю сессию.

Комнаты хранятся 7 дней без активности. При старте новой партии очки и сыгранные роли сбрасываются.

## Локальный запуск

Требуется Node.js 24. Выполняйте команды из корня репозитория:

```sh
npm ci
npm start
```

Откройте [localhost:3000](http://localhost:3000). Локальный сервер хранит комнаты в SQLite. Можно задать `PORT` (по умолчанию `3000`) и `DATA_DIR` (по умолчанию каталог `data` в проекте).

## Проверка и сборка

```sh
npm test
npm run build
```

Тесты проверяют приватность ролей, вход по коду, права участников, таймеры, очки, смену ролей и конкурентные запросы. Сборка создаёт Cloudflare Worker в `dist/server/index.js`.

## Размещение в Cloudflare

Готовая версия работает на Cloudflare Workers с базой D1. Конфигурация находится в `wrangler.jsonc`, привязка базы — `DB`, миграции — в каталоге `drizzle`.

Для размещения в своём аккаунте Cloudflare:

```sh
npm ci
npm run cloudflare:login
npm run cloudflare:db:create
npm run cloudflare:db:remote
npm run cloudflare:check
npm run cloudflare:deploy
```

Команда `cloudflare:db:create` создаёт базу `word-mine-rooms` и обновляет `database_id` в конфигурации. При следующих публикациях применяйте новые миграции командой `cloudflare:db:remote`, затем запускайте `cloudflare:deploy`. Команда `cloudflare:check` проверяет Worker и выполняет пробную сборку публикации без размещения.

Для локального запуска Worker с D1:

```sh
npm run cloudflare:db:local
npm run cloudflare:dev
```
